## Scenario Description
This Dart console program processes a bakery checkout order. It calculates item subtotals, packaging needs using integer division (`~/`) and modulo (`%`) operators, membership discounts, and tests order thresholds using comparison operators (`>=`, `>`).

## Data Types & Operators Used
- **Explicit Types:** `int`, `double`, `String`, `bool`
- **Arithmetic Operators:** `*`, `-`, `~/` (integer division), `%` (modulo)
- **Comparison Operators:** `>=`, `>`
